# Oakarazou Privacy Policy

Static English privacy notice for **Oakarazou Amazon Ads API**.

## Website

Publish `index.html` from the `main` branch, `/ (root)`, using GitHub Pages. No build, dependencies, custom domain, or paid hosting is required.

## Publication steps

1. Sign in to GitHub and create a new **public** repository named `oakarazou-privacy`.
2. Upload only `index.html`, `.nojekyll`, `.gitignore`, and this `README.md` to the repository root.
3. Open **Settings → Pages → Build and deployment**.
4. Select **Deploy from a branch**, then **main** and **/ (root)**; save.
5. Wait for the Pages deployment to complete, then open the actual HTTPS URL shown by GitHub. Confirm that the policy and contact email appear without signing in.
6. Use the verified HTTPS policy URL as the Login with Amazon Security Profile **Consent Privacy Notice URL**.

The public website is only a privacy notice. It is not an OAuth callback, advertising backend, or credential store.

## Content accuracy

Brand, application purpose, primary market, and public contact address were supplied by the operator. The policy sets handling requirements without asserting unverified company details, storage locations, encryption, certifications, processors, or numeric retention periods. The operator must ensure that actual application operation follows these requirements and update the notice when specific practices are determined.

## Keep this repository public-safe

Never upload API keys, OAuth client secrets, access tokens, refresh tokens, advertising reports, account identifiers, logs, backups, or other operational data. Ignore rules are only a precaution; review the exact files before every upload. No tracking scripts, forms, remote fonts, or runtime API calls are included.
