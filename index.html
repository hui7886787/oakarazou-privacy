Oakarazou Amazon Ads API

Privacy Policy

Effective date: 27 November 2026  ·  Last updated: 27 November 2026

This Privacy Policy describes the information handling rules for Oakarazou Amazon Ads API (the “Application”), an internal Amazon advertising management system used by Oakarazou (“we”, “us”, or “our”).

The Application is intended for internal advertising operations, primarily on Amazon Australia. Access to Amazon advertising information depends on authorization from the relevant Amazon account holder.

Application Overview

The Application supports advertising campaign management, advertising report analysis, search term analysis, bid optimization, and budget management. It is intended for Oakarazou’s internal business use rather than as a public advertising management service.

This policy covers the Application and this privacy notice website. Amazon’s own services and websites are governed by Amazon’s applicable privacy notices.

Information We Access

Depending on the permissions granted and the features used, information accessed through the Amazon Ads API may include:

  • Advertising profile and account identifiers, marketplace information, and account settings made available by the API.
  • Campaigns, ad groups, advertised products, targeting settings, keywords, and search term reports.
  • Bids, budgets, campaign status, and advertising performance reports, such as impressions, clicks, spend, and attributed sales or conversions.
  • Authorization credentials issued by Amazon, including access tokens and refresh tokens, where needed to maintain authorized API access.

These categories describe potential access, not a claim that every category is collected. Access must be limited to information needed for the authorized advertising functions. The Application is not intended to collect shoppers’ names, payment details, delivery addresses, or Amazon account passwords.

If you email us, we receive the contact details and information you choose to include in your message. Please do not send passwords, API secrets, or authorization tokens by email.

How We Use Information

Information accessed by the Application may be used to:

  • Create, review, update, and manage advertising campaigns.
  • Generate and analyze advertising performance reports.
  • Evaluate search terms and keyword performance.
  • Support bid optimization and budget allocation.
  • Maintain authorized API connectivity, investigate operational problems, and respond to privacy or deletion requests.

Use is limited to these internal advertising and operational purposes and applicable Amazon API requirements. Advertising information must not be sold or used for unrelated marketing.

Amazon Ads API Authorization

Access requires authorization through Amazon’s authorization process, using Login with Amazon where applicable. The account holder reviews and grants permissions on Amazon’s own authorization pages. The Application must access only the advertising accounts and API resources permitted by that authorization.

Amazon issues tokens for authorized API requests. These tokens are credentials and must be treated as confidential. This public privacy notice website does not provide an Amazon sign-in form, receive OAuth callbacks, or collect authorization tokens.

The Application must not request that users provide their Amazon account password directly to Oakarazou.

Data Storage and Security

Application data and authorization credentials must be kept separate from this public website and its public source repository. Access to them must be limited to personnel and systems that need the information for the purposes described in this policy.

This policy requires confidential handling of credentials, limits on access, and appropriate safeguards for the environment in which the Application is operated. It does not represent that any particular encryption technology, hosting region, audit, or security certification has been implemented. No method of storage or transmission can guarantee absolute security.

This privacy notice is a static website hosted on GitHub Pages. The page does not include analytics scripts, advertising trackers, cookies set by our page code, forms, or external fonts. GitHub may process technical request information when serving the website under the GitHub General Privacy Statement. Hosting this notice does not give GitHub access to the Application’s Amazon advertising data or tokens.

Data Sharing and Disclosure

Advertising information must be used for internal operations and exchanged with Amazon as needed to perform authorized API functions. It must not be published in this website or its repository, sold, or shared for unrelated third-party advertising.

If a service provider is engaged to process Application information, access must be limited to the relevant operational purpose and subject to appropriate confidentiality and data handling obligations. This statement does not identify or imply that any particular cloud provider, AI service, or other processor is currently used.

Information may also be disclosed when required by applicable law or a valid legal process. Any such disclosure must be limited to what is required.

Data Retention and Deletion

Information must be retained only for as long as needed for the purposes described in this policy, applicable Amazon requirements, or applicable legal obligations. Tokens must not be retained for continued API use after access has been revoked.

You may request deletion of information associated with an authorized account by contacting the email address below. We will verify the request and the requester’s authority, identify the affected information, and arrange deletion of information no longer needed or required to be retained. Where retention is required, we will explain the reason in our response.

This policy does not promise a fixed deletion deadline or a specific backup schedule. You may contact us to ask about the handling and retention of information associated with your account. Revoking API access stops future authorized access; it does not itself delete information previously obtained.

Revocation of Authorization

The account holder may revoke the Application’s authorization through Amazon’s account or application authorization settings, where available. You may also contact us to request that use of the authorization stop. Do not include a token or secret in that request.

Following revocation, the Application must stop using the revoked authorization to access the associated Amazon advertising resources. Previously obtained information is subject to the retention and deletion rules above. Features that depend on API access will no longer function for that authorization unless access is granted again.

Changes to This Privacy Policy

We may update this policy to reflect changes to the Application, information handling practices, or applicable requirements. The current version will be published on this page with an updated “Last updated” date. Material changes must be communicated to affected authorized users as appropriate before new uses of their information begin.
